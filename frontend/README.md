# Frontend - Sistema Mercado

Vue 3 frontend com Composition API e Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Estrutura

- `src/components/` - Componentes reutilizáveis
- `src/views/` - Páginas
- `src/composables/` - Composables (lógica reutilizável)
- `src/stores/` - Pinia stores
- `src/router/` - Configuração de rotas
- `src/config/` - Configurações

## Variáveis de Ambiente

Copie `.env.example` para `.env.local` e ajuste conforme necessário.
